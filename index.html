Téléchargez DALIA-Setup-1.0.0.msi. Windows SmartScreen peut afficher un avertissement la première fois — cliquez sur Plus d'infos · Exécuter quand même.

Double-clic, accepter la licence MIT. DALIA s'installe par défaut dans %LOCALAPPDATA%\\Programs\\DALIA. Durée < 30 secondes.

Questions fréquentes.

BONUS
TL;DR · LISEZ-MOI
// 01

DALIA est-elle conforme aux Riot ToS ?

Oui. DALIA lit l'API publique LCU (locale) du client League — la même que celle utilisée par les outils tiers acceptés. Aucune lecture mémoire, aucun hook in-game, aucun overlay au-dessus du jeu. L'app vit en parallèle, jamais par dessus.

// 02

Faut-il héberger un serveur ?

Non. Le backend tourne en permanence, rien à configurer de votre côté. Il suffit de télécharger l'app, de créer un compte et de jouer.

// 03

Pourquoi un mode anonyme ?

Pour tester rapidement sans inscription. En mode anonyme, le client envoie le pool dans le body de chaque requête — pas d'historique ni de DuoQ. L'authentification (JWT) débloque tout : pool persistant, historique, liaison duo, stats Riot.

// 04

Que fait DraftNet exactement ?

C'est un réseau de neurones PyTorch entraîné sur les matchs Master+ collectés via la Riot API. La sortie est une probabilité de victoire calibrée, fusionnée avec le scoring heuristique pour produire la recommandation finale.

// 05

Mac et Linux ?

Le shell Tauri est cross-platform mais le connecteur LCU dépend de chemins Windows (lockfile, registre). macOS / Linux arriveront quand le client League aura un support natif sur ces plateformes — autant dire jamais. Une version cloud sans LCU est à l'étude.

// 06

Open source ?

Licence MIT. Code complet dispo. Forks, PRs et issues bienvenus — pour proposer des règles d'edge case, raffiner les heuristiques de synergie ou améliorer le scraper Lolalytics.
